# Save & Serve

Save & Serve is a Progressive Web Application (PWA) designed to connect food donors with receivers, helping reduce food waste and improve food accessibility. The platform enables donors to share surplus food and allows receivers to view and claim available donations through a simple and user-friendly interface.

## Live Demo

 ![Save and Serve ](https://save-and-serve.netlify.app/)

## Project Overview

Food wastage is a significant global challenge, while many individuals and communities continue to face food insecurity. Save & Serve addresses this issue by providing a digital platform that bridges the gap between food donors and receivers, promoting sustainable food distribution and community welfare.

## Features

- Food donation registration and management
- Receiver registration and access
- View available food donations
- Donation claim functionality
- Responsive user interface
- Progressive Web App (PWA) support
- Offline functionality using Service Workers
- Local storage-based data management

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Progressive Web App (PWA)
- Service Workers
- Web App Manifest
- Local Storage

## Project Objective

The objective of Save & Serve is to reduce food wastage by creating a platform where surplus food can be efficiently shared with individuals or organizations in need. The project demonstrates the use of modern web technologies to address a real-world social challenge through a practical and accessible solution.
